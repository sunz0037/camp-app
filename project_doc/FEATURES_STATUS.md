## ✅ 一、用户认证与授权模块

### 1.1 后端接口（已实现）

| 接口路径 | 方法 | 功能说明 | 状态 | 备注 |
|---------|------|---------|------|------|
| `/api/auth/login` | POST | 多身份登录（学生/教工/访客） | ✅ | 支持学号/工号登录，BCrypt加密 |
| `/api/auth/activate` | POST | 首次登录激活（设置密码） | ✅ | 姓名验证 + 密码设置（最少6位） |
| `/api/auth/logout` | POST | 用户登出 | ✅ | 清除本地存储 |

| `/api/auth/reset-password` | POST | 重置密码 | ✅ | 学生六要素验证/教工验证码验证 |

### 1.2 前端功能（已实现）

| 功能模块 | 页面/组件 | 状态 | 说明 |
|---------|-----------|------|------|
| 登录页面 | `LoginPage.vue` | ✅ | 支持身份选择、学号/工号登录 |
| 登录页面2 | `LoginPage2.vue` | ✅ | 新UI风格的登录页面 |
| 首次激活 | `ActivatePasswordDialog.vue` | ✅ | 首次登录密码设置弹窗 |
| 密码重置 | `ResetPasswordPage.vue` | ✅ | 学生/教工密码重置流程 |

### 1.3 技术实现

- **密码加密**：BCrypt（强度5）
- **多身份登录**：学生（学号）、教工（工号）、访客（仅UI）
- **首次激活**：姓名验证 + 密码设置
- **密码重置**：
  - 学生：六要素验证（学号+姓名+身份证+应急联系人+电话+关系）
  - 教工：工号+姓名+手机号+验证码
  - 重置后密码：身份证后六位

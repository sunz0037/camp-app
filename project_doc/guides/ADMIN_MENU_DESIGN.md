# 管理员菜单设计

### 2. 学生管理
- 学生信息管理
- 学生应急联系人管理
- 考勤管理

### 3. 教学管理
- 课程管理
- 考试成绩管理

### 4. 系统管理
- 用户管理
- 角色权限管理
- 数据查询权限管理
- 教师班级关联管理
- 年级管理员年级关联管理

### 5. 校园管理
- 校园公告管理
- 用户来访登记管理

- 批量导入导出
- 统计报表

- 个人信息
- 修改密码

## 三、菜单路由映射

| 菜单项 | 路由路径 | 说明 |
|--------|---------|------|
| 首页 | `/home` | 首页仪表盘 |
| 学生信息管理 | `/students` | 学生信息列表 |
| 学生应急联系人管理 | `/emergency-contacts` | 应急联系人管理 |
| 考勤管理 | `/attendance` | 考勤管理 |
| 课程管理 | `/courses` | 课程列表 |
| 考试成绩管理 | `/scores` | 成绩管理 |
| 用户管理 | `/users` | 用户管理 |
| 角色权限管理 | `/roles` | 角色权限管理 |
| 数据查询权限管理 | `/data-permissions` | 数据权限配置 |
| 教师班级关联管理 | `/teacher-classes` | 教师班级关联 |
| 年级管理员年级关联管理 | `/grade-admin-grades` | 年级管理员关联 |
| 校园公告管理 | `/announcements` | 公告管理 |
| 用户来访登记管理 | `/visitors` | 来访登记管理 |
| 批量导入导出 | `/batch-operations` | 批量操作 |
| 统计报表 | `/statistics` | 统计报表 |
| 个人信息 | `/profile` | 个人信息 |
| 修改密码 | `/change-password` | 修改密码 |
